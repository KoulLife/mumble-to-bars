# 모음 템플릿 스키마

구현: `src/mumble_to_bars/schema.py`. 오디오 단계와 가사 단계는 이 형식으로만 데이터를 주고받는다.

## Syllable

```json
{"vowel": "ㅡ", "coda": "ㄹ", "start_ms": 1200, "duration_ms": 340, "pitch_hz": null}
```

| 필드 | 타입 | 설명 |
|---|---|---|
| `vowel` | str | 한국어 중성 자모 21개 중 하나 (필수) |
| `coda` | str \| null | 받침. 대표음 7개(ㄱㄴㄷㄹㅁㅂㅇ)로 정규화 |
| `start_ms` | int \| null | 음절 시작 시각 |
| `duration_ms` | int \| null | 음절 길이 |
| `pitch_hz` | float \| null | 대표 음높이. 지금은 비워둔다 |

모음 템플릿은 `Syllable`의 리스트다.

## 표기

- 내부 표기는 **자모**를 쓴다.
- 영어 혼용과 언어 간 라임(money/머니) 비교를 위해 IPA로 바꿀 때는 `schema.to_ipa()`만 쓴다. 변환 로직은 다른 곳에 두지 않는다.

## 미정 사항

| 항목 | 선택지 | 비고 |
|---|---|---|
| ㅐ/ㅔ 병합 | 하나로 합치기 / 구분 유지 | 현대 한국어 발화에서 거의 구분되지 않는다. 구분하면 모델이 계속 틀리는 클래스가 될 수 있다 |
| 이중모음 | `vowel`에 그대로 / `glide` 필드 분리 | 라임은 핵모음(ㅑ→ㅏ) 기준이 유리하다 |
| 쉼(rest) | 별도 토큰 / `start_ms` 간격으로 추론 | 랩 플로우에서 쉼은 음절만큼 중요하다 |
| 강세, 박자 정렬 | 필드 추가 여부 | BPM, 비트 위치는 생성 단계에서 다시 검토 |
| 영어 음절 | 발음 후보 여러 개 | 예: street은 1음절 / 스트리트는 3음절 |
