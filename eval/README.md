# 평가셋

`manifest.jsonl`은 한 줄에 샘플 하나씩 정답 모음열을 담는다. 이 파일은 커밋하고, 오디오는 `data/eval/`에 두되 커밋하지 않는다.

```json
{"id": "hum_001", "audio": "data/eval/hum_001.wav", "vowels": ["ㅏ", "ㅡ", "ㅏ", "ㅡ"], "note": "늘어지는 모음"}
```

- `vowels`는 **리스트**로 쓴다. 나중에 IPA처럼 여러 글자로 된 토큰이 들어와도 깨지지 않게 하기 위해서다.
- 음절 수는 `len(vowels)`로 계산한다. 별도 필드로 두지 않는다.
- 녹음 형식: 입을 연 발성, 16kHz mono 권장 (다른 형식이면 로딩할 때 변환한다).
- 정답을 바꾸면 버전을 올리고 이유를 아래에 기록한다.
