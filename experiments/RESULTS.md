# 실험 결과 요약

실험별 상세 내용은 각 폴더의 `README.md`에 있다. 실험이 끝나면 여기에 한 줄 추가한다.

| # | 실험 | 날짜 | manifest | 음절 수 정확도 | 모음 오류율 | 결론 |
|---|---|---|---|---|---|---|
| | | | | | | |

## 실험 README 템플릿

```markdown
# NNN. <실험 이름>

- 날짜:
- manifest 버전:

## 가설
## 설정 (모델, 파라미터, 실행 명령)
## 결과 (수치 + 대표 실패 사례)
## 결론 / 다음 단계
```
